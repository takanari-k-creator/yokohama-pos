# 横浜・まちのコンビニPOSシミュレーター（情報Ⅰ 情報システム）

横浜市の**学校の近くの住宅地**にある、架空のコンビニ「じょうほうマート 横浜みどり坂店」を舞台にした教材です。
生徒がお客さんになって買い物をすると、その購入データが集まり、「本部になる」画面でクラス全員のデータを一緒に見られます。

- 生徒の画面：https://takanari-k-creator.github.io/yokohama-pos/?room=2A
- 本部（先生）の画面：同じURLの末尾に `#honbu`（例：`?room=2A#honbu`）
- `room=` の値でクラスを分けます（英数字・ハイフン・アンダーバー、20文字まで）

※ お店は架空です。実在の店舗・チェーンとは関係ありません。

## もとのコンビニPOSシミュレーターとの違い
| 項目 | 横浜版 |
|---|---|
| お客さんの設定 | **客層**（小中学生／高校生／大学生・20代／会社員／主婦・主夫／高齢者）、**来店のきっかけ**（学校・部活の帰り／通勤・通学の途中／家の用事／散歩・近所）、**学校の予定**（ふつうの日／テスト期間／部活の大会・試合／長期休み）を追加 |
| 商品 | 住宅地向け（牛乳・食パン・卵、ノート・シャーペンの芯、からあげ棒など）。横浜らしいシューマイ弁当・サンマーメン（カップ麺） |
| 本部の集計 | 「学校の予定」「来店のきっかけ」「客層」でも集計できる |
| 練習用サンプル | 住宅地らしい傾向（学校帰りの高校生、テスト期間の文房具、家の用事の牛乳・卵など）が出るように作ってある |

データの形式（提出用コードは `YPOS-` で始まる）が違うため、もとの教材とはデータが混ざりません。

## 自動共有にするには（任意）
`GAS_URL` が空のままなら、生徒が「提出用コード」をClassroomなどに貼り、先生がまとめて本部画面に貼り付ける方式で動きます。

自動共有にする場合：
1. 新しいスプレッドシートを作り、「拡張機能」→「Apps Script」に、このリポジトリの `Code.gs` を貼り付ける（**もとのコンビニPOSとは別のスプレッドシート**にしてください）
2. 1行目の `ADMIN_KEY` を好きな合言葉に変えて保存（本物の合言葉はGitHubには書かない）
3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」（実行：自分／アクセス：全員）で、表示されたURLをコピー
4. `index.html` の `const GAS_URL='';` にURLを入れてGitHubに反映

## 授業での使い方
1. 本部（先生）の画面をプロジェクターに映し、生徒にURL（`?room=クラス名` 付き）を配る
2. 生徒はお客さんになって買い物（客層・来店のきっかけ・学校の予定などを変えて何回でも）
3. 本部画面で「データベースの中身」「何が・いつ・だれに売れた？」などを見る
4. 学校の近くのこのお店が、データをどう生かせるか（品ぞろえ・発注・時間帯ごとの準備など）を考える
